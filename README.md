# UTAU音源 月蝕公式サイト

このサイトは、らむらさんのUTAU音源「月蝕」の公式サイトです。

## Architecture

Next.jsで構築されており、[UniPro-tech/ramura-utau-dashboard](https://github.com/UniPro-tech/ramura-utau-dashboard) によって `./data/files` にデータが保存されます。
